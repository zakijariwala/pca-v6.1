# B18 drills

Case study: Cymbal Retail. Read it on Google's exam guide page first. Scenarios are original and paraphrase the case.

### B18-D001 | pillars: operational-excellence, cost
Scenario: Cymbal receives supplier titles, descriptions, and product photos. It wants software to derive product attributes and match them to its catalog structure, with the least development effort. What fits best?
A) Prompt a multimodal Gemini model with the supplier text and images and the catalog's attribute schema, and queue results for review.
B) Train a custom image classifier per product category.
C) Regular expressions over supplier descriptions.
D) Ask suppliers to fill a longer form.
<details><summary>Answer</summary>
A. Why: a multimodal foundation model reads text and images and returns structured attributes from a prompt, with review before publishing.
B fails: needs labeled data for each category and ignores text.
C fails: brittle and can't read images.
D fails: keeps the manual effort the business wants to cut.
Verified: 2026-09-24
</details>

### B18-D002 | pillars: operational-excellence
Scenario: Cymbal wants color variations and new backgrounds for product photos from a single base image, with text overlays. Which option fits?
A) Cloud Vision API label detection.
B) Hire a photo studio for each variation.
C) Image generation and editing models on Agent Platform (Imagen).
D) BigQuery ML.
<details><summary>Answer</summary>
C. Why: image generation models create and edit variations from a base image.
A fails: Vision detects labels; it doesn't generate images.
B fails: manual and slow, which the case wants to avoid.
D fails: SQL-based ML doesn't generate images.

### B18-D003 | pillars: performance
Scenario: Cymbal's site browses products with plain database queries by name and category. Customers want to describe what they need in their own words and get relevant results. What should Cymbal adopt?
A) Add more indexes to the relational database.
B) A self-managed search cluster on Compute Engine.
C) Cache query results in Memorystore.
D) AI Commerce Search (old name: Vertex AI Search for commerce).
<details><summary>Answer</summary>
D. Why: a managed search service built for natural language product discovery and relevance.
A fails: faster exact matching, not natural language understanding.
B fails: adds operations and still needs relevance tuning.
C fails: caching doesn't improve relevance.

### B18-D004 | pillars: cost
Scenario: Cymbal's call center agents key in orders for customers who get stuck. Leadership wants to cut call center staffing cost without hurting service. What fits best?
A) Longer IVR menus.
B) Conversational agents on Gemini Enterprise for Customer Experience that handle common requests, with handoff to human agents.
C) Close the call center.
D) Email-only support.
<details><summary>Answer</summary>
B. Why: AI agents resolve routine requests and pass hard ones to people, cutting staff time per contact.
A fails: frustrates callers and doesn't resolve more requests.
C fails: removes service for customers who need help.
D fails: slower and doesn't automate resolution.

### B18-D006 | pillars: performance, operational-excellence

### B18-D009 | pillars: security
Scenario: Cymbal analysts need purchase trends in BigQuery. Customer names, emails, and phone numbers must not be visible to them. What should Cymbal apply?
A) Sensitive Data Protection to de-identify personal data before or during analysis.
B) Give analysts Viewer on the whole project.
C) Store the data in a different region.
D) Cloud Armor on BigQuery.
<details><summary>Answer</summary>
A. Why: discovers and de-identifies PII (masking, tokenization) while keeping data useful.
B fails: exposes everything.
C fails: location doesn't hide fields.
D fails: Cloud Armor protects load balancers, not datasets.
Verified: 2026-09-24
</details>

### B18-D010 | pillars: security
Scenario: Cymbal handles card payments. It wants to shrink the environment that falls under card data rules. Which approach fits best?
A) Keep card data in the same project as everything else, with more IAM roles.
B) Log full card numbers for debugging.
C) Isolate card data in dedicated projects, tokenize card numbers with Sensitive Data Protection, and put a VPC Service Controls perimeter around those projects.
D) Move card data to a public bucket with signed URLs.
<details><summary>Answer</summary>
C. Why: isolation and tokenization shrink what handles raw card data; the perimeter limits exfiltration.
A fails: widens the regulated scope.
B fails: spreads card data into logs.
D fails: public exposure.
Verified: 2026-09-24
</details>
