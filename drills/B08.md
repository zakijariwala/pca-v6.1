# B08 drills

### B08-D001 | pillars: reliability
Scenario: A Cloud SQL for PostgreSQL database must keep running through a zone failure with no committed writes lost. What should you configure?
A) A read replica in another zone.
B) Daily backups.
C) High availability (regional): a standby in a second zone with synchronous replication.
D) A larger machine type.
<details><summary>Answer</summary>
C. Why: writes commit only after reaching disks in both zones; the standby takes over on failure.
A fails: replicas replicate asynchronously and don't fail over on their own.
B fails: restores lose up to a day.
D fails: size doesn't add zones.
Verified: 2026-09-24
</details>
