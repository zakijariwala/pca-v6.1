# P08 drills

### P08-D001 | pillars: security
Scenario: In the capstone, the Cloud Run service must accept traffic only through the external load balancer, not its `run.app` URL. Which ingress setting?
A) `all`.
B) `internal-and-cloud-load-balancing`.
C) `internal` only, with a public URL.
D) No setting; use firewall rules.
<details><summary>Answer</summary>
B. Why: allows internal traffic and traffic from Cloud Load Balancing, blocking direct public calls.
A fails: allows direct calls to the `run.app` URL.
C fails: blocks the external load balancer's traffic.
D fails: Cloud Run isn't a VM behind VPC firewall rules.
Verified: 2026-09-24
</details>
