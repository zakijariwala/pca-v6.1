# B20 drills

Case study: KnightMotives Automotive. Read it on Google's exam guide page first. Scenarios are original and paraphrase the case.

### B20-D001 | pillars: security
Scenario: KnightMotives is building an autonomous driving platform for EU markets. Regulators expect data residency, limits on which support personnel can access data, and a defined compliance boundary. What should it use?
A) A single global project with no location rules.
B) Cloud CDN in Europe.
C) Assured Workloads with a control package for the EU requirements.
D) Committed use discounts in EU regions.
<details><summary>Answer</summary>
C. Why: Assured Workloads applies control packages for residency and personnel access in a defined boundary.
A fails: no controls at all.
B fails: caching, not compliance.
D fails: a pricing option.
Verified: 2026-09-24
</details>

### B20-D002 | pillars: operational-excellence, reliability
Scenario: KnightMotives' supply chain runs on an old mainframe. New dealer tools need order and inventory data now; the mainframe can't be replaced this year. What should you do first?
A) Put an API layer (Apigee) in front of mainframe services, reached over a private hybrid link, and build dealer tools on those APIs.
B) Replace the mainframe in one cutover.
C) Give dealer apps direct terminal access to the mainframe.
D) Copy the mainframe database to spreadsheets nightly.
<details><summary>Answer</summary>
A. Why: APIs decouple new apps from the legacy system, so modernization can proceed behind them in stages.
B fails: a big-bang replacement the case rules out.
C fails: insecure and ties apps to legacy interfaces.
D fails: stale, manual data.
Verified: 2026-09-24
</details>

### B20-D003 | pillars: reliability, performance
Scenario: KnightMotives' plants must keep processing sensor data when their WAN links to headquarters drop. It wants the same tooling as its cloud workloads. What fits?
A) Run everything in a single cloud region.
B) Local spreadsheets during outages.
C) Stop processing until the link returns.
D) Google Distributed Cloud at each plant, managed alongside cloud clusters.
<details><summary>Answer</summary>
D. Why: extends Google Cloud infrastructure and Kubernetes to on-site locations, so processing continues on site.
A fails: depends on the WAN that drops.
B fails: manual and unsafe for production.
C fails: loses production data and time.
Verified: 2026-09-24
</details>

### B20-D004 | pillars: operational-excellence, reliability
Scenario: KnightMotives has apps on-prem, on Google Cloud, and on another major cloud. It wants any-to-any private connectivity managed from one place. What fits?
A) VPC Network Peering between every pair of networks.
B) A Network Connectivity Center hub, with hybrid spokes for on-prem links and Cross-Cloud Interconnect to the other cloud.
C) Public internet with IP allowlists.
D) One VPN tunnel per application.
<details><summary>Answer</summary>
B. Why: NCC exchanges routes among spokes through one hub; Cross-Cloud Interconnect gives private links to other clouds.
A fails: peering isn't transitive and doesn't reach other clouds or on-prem.
C fails: not private.
D fails: sprawl with no central management.
Verified: 2026-09-24
</details>

### B20-D005 | pillars: performance
Scenario: KnightMotives' research team trains very large autonomous driving models with a framework that runs on Google's custom ML accelerators, and needs high throughput on large matrix operations. Which accelerator family fits?
A) General-purpose CPUs.
B) Local SSD.
C) TPUs.
D) Memory-optimized VMs without accelerators.
<details><summary>Answer</summary>
C. Why: TPUs are Google's ASICs built for the large matrix operations in ML training.
A fails: far slower for large-model training.
B fails: storage, not compute.
D fails: memory without ML acceleration.

</details>

### B20-D008 | pillars: security

A) A second IAM role.

### B20-D009 | pillars: operational-excellence
Scenario: KnightMotives' IT staff have little cloud experience, and business and technical teams struggle to agree on priorities. Which plan addresses the case's people requirements?
A) Hire a vendor to run everything with no knowledge transfer.
B) Pick the most advanced services and let the team learn on production.
C) A training and certification plan, managed services to lower the ops load, joint business-IT planning with agreed metrics, and a staged rollout.
D) Postpone the cloud program until the team is fully trained.
<details><summary>Answer</summary>
C. Why: it builds skills, reduces what the team must operate, and aligns the business and IT on outcomes.
A fails: no upskilling, which the case lists as a goal.
B fails: risky for a team new to the platform.
D fails: stalls the business goals.
Verified: 2026-09-24
</details>

### B20-D010 | pillars: cost, operational-excellence
Scenario: KnightMotives is building web tools for dealers. Usage spikes during business hours and falls to near zero overnight. Dealers have no budget for new hardware, and the team is small. Where should the tools run?
A) Cloud Run.
B) New servers at each dealership.
C) GKE Standard with custom node pools.
D) A fixed-size fleet of Compute Engine VMs running 24/7.
<details><summary>Answer</summary>
A. Why: browser-based tools on Cloud Run need no dealer hardware, scale with demand, and scale to zero overnight.
B fails: dealers can't buy hardware.
C fails: more operations than a small team needs.
D fails: pays for idle capacity overnight.
Verified: 2026-09-24
</details>
