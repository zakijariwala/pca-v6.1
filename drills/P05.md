### P05-D001 | pillars: security
Scenario: An auditor asks for a list of every principal who can read a sensitive BigQuery dataset, including through groups and inherited grants. Which tool?
A) Policy Analyzer.
B) Policy Troubleshooter.
C) Cloud Trace.
D) VPC Flow Logs.
<details><summary>Answer</summary>
A. Why: answers "who has what access to which resources" across the hierarchy.
B fails: answers one principal, one resource, one permission.
C fails: request latency.
D fails: network flows.

</details>

### P05-D003 | pillars: security
Scenario: A bucket was deleted yesterday. Which log answers who did it, and is it on by default?
A) Data Access logs; off by default.
B) VPC Flow Logs; on by default.
C) Admin Activity audit logs; always on.
D) Access Transparency logs; on by default.
<details><summary>Answer</summary>
C. Why: deleting a bucket is an admin action, recorded in Admin Activity logs, which can't be disabled.
A fails: records data reads, not deletes.
B fails: network traffic.
D fails: Google staff access.
Verified: 2026-09-24
</details>

### P05-D004 | pillars: security
Scenario: Compliance needs a record of who read objects in a Cloud Storage bucket from now on. What must the team do?
A) Nothing; Admin Activity logs capture reads.
B) Turn on Data Access audit logs for Cloud Storage.
C) Turn on VPC Flow Logs.
D) Enable object versioning.
<details><summary>Answer</summary>
B. Why: Data Access logs are off by default for most services, including Cloud Storage.
A fails: Admin Activity doesn't record data reads.
C fails: flows don't name the reader or object.
D fails: versioning keeps old copies; it doesn't log reads.
Verified: 2026-09-24
</details>

### P05-D005 | pillars: security
Scenario: Audit logs must be kept for 5 years. Admin Activity logs sit in `_Required`. What's true?
A) `_Required` keeps them for 400 days and can't be changed; route logs to longer-term storage with a sink.
B) Set `_Required` retention to 5 years.
C) `_Required` keeps them forever.
D) `_Default` keeps them for 5 years by default.
<details><summary>Answer</summary>
A. Why: `_Required` retention is fixed at 400 days; longer retention needs a sink to a custom bucket, Cloud Storage, or BigQuery.
B fails: you can't change `_Required` retention.
C fails: 400 days.
D fails: `_Default` defaults to 30 days.
Verified: 2026-09-24
</details>

### P05-D009 | pillars: security
Scenario: What's the correct permission format in a deny policy that blocks bucket deletion?
A) `storage.buckets.delete`.
B) `roles/storage.admin`.
C) `buckets:delete`.
D) `storage.googleapis.com/buckets.delete`.
<details><summary>Answer</summary>
D. Why: deny policies name permissions as `SERVICE.googleapis.com/RESOURCE.VERB`.
A fails: allow-policy permission format.
B fails: a role, not a permission.
C fails: not a valid format.

</details>
