### P01-D001 | pillars: operational-excellence
Scenario: A nightly script ran against production because an engineer had left the `prod` configuration active in their shell. How should the script be changed?
A) Pass `--project` on every command in the script.
B) Tell engineers to always activate `dev` before leaving.
C) Delete the `prod` configuration.
D) Run the script from the console.
<details><summary>Answer</summary>
A. Why: an explicit target in the script removes the dependency on whatever configuration is active.
B fails: relies on memory.
C fails: engineers still need prod access.
D fails: the console doesn't run scripts.

</details>

### P01-D002 | pillars: operational-excellence
Scenario: A loop needs only the names of stopped VMs, one per line. Which flags produce that?
A) `--format=table` and `grep TERMINATED`.
B) `--format=json` and read by eye.
C) `--filter="status=TERMINATED"` and `--format="value(name)"`.
D) `--filter="name=TERMINATED"`.
<details><summary>Answer</summary>
C. Why: `--filter` selects the resources; `value(name)` prints just the names.
A fails: table output changes shape; parsing it breaks.
B fails: not scriptable.
D fails: filters on the wrong field.
Verified: 2026-09-24
</details>

### P01-D003 | pillars: security
Scenario: In a new project, `gcloud compute instances list` fails with an error that the API isn't enabled. A teammate suggests granting Owner. What should you do?
A) Grant Owner.
B) Grant Compute Admin.
C) Wait for the API to enable itself.
D) Enable the API with `gcloud services enable compute.googleapis.com`, using an account allowed to enable services.

C fails: APIs don't enable themselves.

</details>

### P01-D005 | pillars: security
Scenario: A developer needs to test with a production service account's permissions for one afternoon, from Cloud Shell. What's the best approach?
A) Download the service account's key.
B) Add the developer to the production Owners group.
C) Grant the developer Service Account Token Creator on that service account and use `--impersonate-service-account`.
D) Share one admin's user login for the afternoon.
<details><summary>Answer</summary>
C. Why: impersonation gives short-lived credentials; no key is created.
A fails: a long-lived secret.
B fails: far broader than needed.
D fails: shared logins remove accountability and far exceed the need.
Verified: 2026-09-24
</details>

### P01-D010 | pillars: operational-excellence
Scenario: You need a CSV of VM name, zone (short form), and status for a report, using only gcloud. Which format fits?
A) `--format=json`.
B) `--format=table`.
C) `--format="csv(name,zone.basename(),status)"`.
D) `--format=yaml`.
<details><summary>Answer</summary>
C. Why: the CSV projection selects fields and `basename()` trims the zone URL.
A fails: JSON, not CSV.
B fails: human-readable table, not CSV.
D fails: YAML, not CSV.
Verified: 2026-09-24
</details>
