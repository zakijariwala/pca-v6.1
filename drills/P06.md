### P06-D001 | pillars: operational-excellence
Scenario: Which Logging query returns ERROR-or-worse entries from Cloud Run revisions?
A) `resource.type="cloud_run_revision" AND severity>=ERROR`
B) `severity=ERROR OR cloud_run`
C) `textPayload:"ERROR"` only
D) `resource.type=cloud_run AND level=error`
<details><summary>Answer</summary>
A. Why: filters on the resource type and a severity threshold.
B fails: matches the wrong things and misses CRITICAL and above.
C fails: misses entries without that text and matches unrelated ones.
D fails: wrong resource type and field.
